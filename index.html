SECTION 16A

Transformations of Graphs

Three Types of Transformation

To transform a familiar graph (e.g. y = 1/x) into a more complicated one, you need to know three types: Translations, Stretches, and Reflections.

■ Translations

KEY POINT 16.1
y = f(x) + b is a vertical translation by b of y = f(x).
Tip: b can be negative — this results in a downward translation.
KEY POINT 16.2
y = f(x + c) is a horizontal translation by −c of y = f(x).
Tip: y = f(x + c) moves to the left by c, not to the right.

Proof 16.1 — Horizontal Translation

Let y₁ = f(x₁) on the original curve and y₂ = f(x₂ + c) on the transformed curve.

If x₁ = x₂ + c, then y₁ = y₂. Rearranging: x₂ = x₁ − c.

So the point (x₁, y) on y = f(x) maps to (x₁ − c, y) on y = f(x + c) — a horizontal shift of −c.

■ Stretches

KEY POINT 16.3
y = pf(x) is a vertical stretch with scale factor p of y = f(x).
Tip: p can be a fraction less than one (compression).
KEY POINT 16.4
y = f(qx) is a horizontal stretch with scale factor 1/q of y = f(x).

■ Reflections

KEY POINT 16.5
y = −f(x) is a reflection in the x-axis of y = f(x).
KEY POINT 16.6
y = f(−x) is a reflection in the y-axis of y = f(x).
Tip: Alterations inside the brackets affect x-coordinates (horizontal); outside the brackets affect y-coordinates (vertical).

■ Composite Transformations

KEY POINT 16.7
  • When two vertical transformations are applied, order matters: y = pf(x) + b is a vertical stretch (×p) followed by a vertical translation (+b).
  • When one vertical and one horizontal transformation are applied, order does not matter.
SECTION 16A

Worked Examples

Worked Example 16.1

Question: The graph of y = f(x) has a peak at (1, 4) and passes through (3, 0). Sketch the graph y = f(x) − 4.

SOLUTION

y = f(x) − 4 is a vertical translation by −4 (Key Point 16.1).

Every y-coordinate decreases by 4:

  • Peak (1, 4) → (1, 0)
  • Point (3, 0) → (3, −4)

The shape is identical, shifted 4 units down.

Worked Example 16.2

Question: The graph of y = x² − 3x + 5 is translated to the left by 2 units. Find the equation of the resulting graph in the form y = ax² + bx + c.

SOLUTION

Let f(x) = x² − 3x + 5. Translation left 2 means horizontal translation by −2, so new graph is y = f(x + 2).

y = (x+2)² − 3(x+2) + 5 = x² + 4x + 4 − 3x − 6 + 5 = x² + x + 3

Worked Example 16.3

Question: The graph of y = f(x) has peak at (1, 4). Sketch y = f(⅓x).

SOLUTION

y = f(⅓x) is a horizontal stretch with scale factor 1/(1/3) = 3 (Key Point 16.4).

Every x-coordinate is multiplied by 3: peak (1, 4) → (3, 4). The curve is stretched horizontally.

Worked Example 16.4

Question: Describe the transformation mapping y = 2x² − 8x − 5 to y = x² − 4x − 2.5.

SOLUTION

Let f(x) = 2x² − 8x − 5. Then:

x² − 4x − 2.5 = ½(2x² − 8x − 5) = ½f(x)

This is a vertical stretch with scale factor ½.

Worked Example 16.5

Question: The graph of y = f(x) has a single vertex at (5, −2). Find the coordinates of the vertex of y = f(−x).

SOLUTION

y = f(−x) is a reflection in the y-axis — the x-coordinate is multiplied by −1.

Vertex: (5, −2) → (−5, −2)

Worked Example 16.6

Question: The graph of y = f(x) has key points (−1, 6) and (3, −10). Sketch (a) y = 3f(x − 2) and (b) y = −f(x) + 4.

SOLUTION

(a) y = 3f(x − 2): One vertical and one horizontal transformation — order doesn't matter.

  • Horizontal translation +2: (−1,6)→(1,6), (3,−10)→(5,−10)
  • Vertical stretch ×3: (1,6)→(1,18), (5,−10)→(5,−30)

(b) y = −f(x) + 4: Two vertical transformations — order matters.

  • First reflect in x-axis: (−1,6)→(−1,−6), (3,−10)→(3,10)
  • Then translate +4: (−1,−6)→(−1,−2), (3,10)→(3,14)

Worked Example 16.7

Question: Describe a sequence of transformations mapping y = x³ − x to y = 2x³ − 2x − 1.

SOLUTION

Let f(x) = x³ − x. Then:

2x³ − 2x − 1 = 2(x³ − x) − 1 = 2f(x) − 1

Vertical stretch with scale factor 2, followed by vertical translation by −1.

(Since both are vertical, order matters: stretch first, then translate.)

SECTION 16B

Rational Functions

Definition

A linear rational function is any function that can be written as a fraction where both the numerator and denominator are linear expressions.

■ The Reciprocal Function f(x) = 1/x

KEY POINT 16.8
The graph of y = 1/x is a hyperbola with:
  • Domain: x ∈ ℝ, x ≠ 0
  • Range: f(x) ∈ ℝ, f(x) ≠ 0
  • Asymptotes: x = 0 (y-axis) and y = 0 (x-axis)
  • Symmetrical about y = x
Self-inverse function: The inverse of f(x) = 1/x is f⁻¹(x) = 1/x — reflecting y = 1/x in the line y = x gives y = 1/x again.

■ Rational Functions f(x) = (ax + b)/(cx + d)

KEY POINT 16.9
For f(x) = (ax + b)/(cx + d):
  • y-intercept: x = 0 → y = b/d
  • x-intercept: y = 0 → x = −b/a
  • Vertical asymptote: denominator = 0 → x = −d/c
  • Horizontal asymptote: as x → ±∞ → y = a/c
The shape is a hyperbola (same shape as y = 1/x).

Worked Example 16.8

Question: Sketch the graph of y = (2x + 3)/(x + 4), clearly labelling all asymptotes and axis intercepts.

SOLUTION

Here a = 2, b = 3, c = 1, d = 4.

  • y-intercept: y = b/d = 3/4 → point (0, 3/4)
  • x-intercept: x = −b/a = −3/2 → point (−3/2, 0)
  • Vertical asymptote: x = −d/c = −4
  • Horizontal asymptote: y = a/c = 2

The graph is a hyperbola with two branches. Remember: always include the top-left branch!

Tip: When using a calculator to sketch rational functions, the top-left branch is often missed. Hyperbolas always have two branches.

SECTION 16C

Exponential and Logarithmic Functions

■ Exponential Functions y = aˣ

KEY POINT 16.10
The graph of y = aˣ (a > 0) has two shapes:
  • a > 1: Increasing exponential (grows rapidly)
  • 0 < a < 1: Decreasing exponential (decays)
In both cases: passes through (0, 1) since a⁰ = 1. The x-axis (y = 0) is an asymptote.
Note: When a = 1, the graph is just y = 1 (a horizontal line) — this is NOT considered an exponential graph.

Worked Example 16.9

Question: Sketch the graph of y = 4⁻ˣ, stating any axis intercepts and asymptotes.

SOLUTION

Use laws of exponents: y = 4⁻ˣ = (4⁻¹)ˣ = (¼)ˣ

This has the standard shape of y = aˣ for 0 < a < 1 (decreasing).

  • y-intercept: (0, 1)
  • Asymptote: y = 0 (the x-axis)

Note: y = 4⁻ˣ can also be seen as a reflection of y = 4ˣ in the y-axis.

■ Logarithmic Functions y = logₐ(x)

KEY POINT 16.11
The graph of y = logₐ x (a, x > 0) has two shapes:
  • a > 1: Increasing, passes through (1, 0), y-axis is asymptote
  • 0 < a < 1: Decreasing, passes through (1, 0), y-axis is asymptote
KEY POINT 16.12 — Inverse Relationship
aloga x = x     and     loga(ax) = x

y = ax and y = loga x are inverse functions — one is a reflection of the other in the line y = x.

KEY POINT 16.13 — Change of Base
ax = ex ln a

It is sometimes useful to convert any exponential to base e.

Worked Example 16.10

Question: On the same axes, sketch y = 3ˣ and y = log₃ x, clearly showing the relationship.

SOLUTION

y = 3ˣ and y = log₃ x are inverse functions, so one is the reflection of the other in the line y = x.

  • y = 3ˣ passes through (0, 1) and (1, 3)
  • y = log₃ x passes through (1, 0) and (3, 1)
  • Both are reflections of each other in y = x

Worked Example 16.11

a) Show that aˣ = e^(x ln a) for a > 0.

b) Write 5ˣ in the form e^(kx), giving k to 3 s.f.

SOLUTION

a) Using x ln a = ln(aˣ): e^(x ln a) = e^(ln(aˣ)) = aˣ ✓

b) 5ˣ = e^(x ln 5) = e^(1.61x), so k = 1.61

Be the Examiner 16.1 — Which solution is correct?

Transformations applied to y = ln x: (1) translate up 5, (2) horizontal stretch ×2, (3) reflect in x-axis.

Solution 1Solution 2Solution 3 ✓
y = −ln(2x) + 5y = −ln(x/2) − 5y = −ln(x/2) + 5

Correct: Solution 3. Horizontal stretch ×2 replaces x with x/2 (not 2x). Reflection in x-axis negates the whole function: −(ln(x/2) + 5) = −ln(x/2) − 5 is wrong; −(ln(x/2)) + 5 = −ln(x/2) + 5 ✓ (reflect after translating up preserves +5).
